OOP - is a programming paradigm that uses objects and classes to structure code.

It allows for encapsulation, inheritance, and polymorphism, making it easier to manage and maintain complex software systems.

"""

Object-oriented programming languages ​​adopt and implement the principles and concepts of OOP.
These languages—such as Python, Java, C++, C#, and Ruby—allow programmers to create software that is modular, reusable, and easier to understand and maintain.
OOP is a programming paradigm based on organizing programs around objects, which are instances of classes. Classes are blueprints that define the structure and behavior of objects.
Within classes, we can define attributes and methods, the latter representing the actions objects can perform.
The constructor is a special method that allows us to define the class's attributes.

"""
Objects are created from a class and possess the same attributes and methods defined within that class.
Attributes represent the class's data, while methods are the functions the class can perform.

To create an object, we define a variable that holds an instance of the class, passing in the necessary attribute values.
We can access an object's attributes using dot notation.
We can also add methods to the class to perform specific actions; objects created from the class can then call these methods.
Object-oriented programming offers advantages such as code reusability, organization, and structure, alongside the core pillars of OOP: encapsulation, inheritance, polymorphism, and abstraction. However, it also presents disadvantages, such as complexity and a learning curve.
